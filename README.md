# MacroKnot

MacroKnot은 macOS에서 마우스와 키보드 동작을 녹화하고 다시 실행하는 네이티브 매크로 앱입니다.

## 주요 기능

- 마우스 클릭·더블클릭·우클릭·이동·드래그·스크롤과 키 입력 녹화
- 녹화된 입력 사이 시간 간격 보존
- 시간순 액션 목록 확인·삭제·순서 변경
- 버전형 JSON 매크로 문서의 새로 만들기·열기·저장·다른 이름으로 저장
- 좌표 기반 입력, 대기, 유한 반복 재생과 앱 화면의 중지 버튼
- 재생 중 전역 `Control + Escape` 강제 중지

## 지원 환경

- macOS 14 이상
- 입력 녹화·재생을 위한 macOS 손쉬운 사용 권한
