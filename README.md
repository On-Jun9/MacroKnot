# MacroKnot

MacroKnot은 macOS에서 마우스와 키보드 동작을 녹화하고 다시 실행하는 네이티브 매크로 앱입니다.

## 주요 기능

- 마우스 클릭·더블클릭·우클릭·이동·드래그·스크롤과 키 입력 녹화
- 녹화된 입력 사이 시간 간격 보존
- 매크로 보관함에서 저장·편집·복제·삭제와 JSON 가져오기·내보내기
- 독립 편집 창에서 액션 추가·수정·순서 변경·범위 반복 묶기
- 편집 실행 취소·재실행(⌘Z / ⇧⌘Z)과 액션 복사·붙여넣기·복제(⌘C / ⌘V / ⌘D)
- 작성 중 초안 자동 저장과 비정상 종료 후 복구
- 재생 속도 조절과 유한·무한 반복 재생, 앱 화면의 중지 버튼
- 디스플레이·앱·창을 대상으로 한 PNG 캡처 액션
- 설정 가능한 전역 녹화 시작·중지 및 재생 단축키
- 재생 중 전역 `Control + Escape` 강제 중지

## 설치

1. [Releases](../../releases)에서 최신 버전을 내려받아 `MacroKnot.app`을 응용 프로그램 폴더로 옮깁니다.
2. MacroKnot은 Apple 공증 없이 배포되므로 처음 실행하면 macOS가 실행을 차단합니다. 차단 안내가 뜨면 **시스템 설정 → 개인정보 보호 및 보안** 아래의 **"그래도 열기"** 를 누른 뒤 다시 실행합니다. 터미널을 쓴다면 다음 한 줄로도 차단을 해제할 수 있습니다.

   ```sh
   xattr -d com.apple.quarantine /Applications/MacroKnot.app
   ```

3. 첫 실행 후 안내에 따라 손쉬운 사용·화면 기록 권한을 허용합니다.

### 알려진 제한

- Apple Developer 인증서로 서명되지 않아, 앱을 업데이트하면 손쉬운 사용·화면 기록 권한을 다시 허용해야 할 수 있습니다.

## 지원 환경

- Apple Silicon Mac의 macOS 14 이상
- 입력 녹화·재생을 위한 macOS 손쉬운 사용 권한
- 디스플레이·앱·창 캡처를 위한 macOS 화면 기록 권한
